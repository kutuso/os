What you get

A complete desktop that treats memory
as the scarce resource it now is

Everything ships as ordinary pacman packages with safe defaults — no config files to babysit, no daemons to babysit either.

Memory that goes further

zstd-compressed zswap, MGLRU page aging and DAMON proactive reclaim target a 20–40% smaller effective working set — the design goal the whole distro is built around.

Tunes itself on first boot

RAM-size calibration picks saver, balanced or performance mode. Per-app and session-wide memory ceilings are set before your desktop even starts.

Click-to-install, offline

Boot the live USB, poke around, then let the Calamares installer put it on disk. No accounts, no network, no “call home” — the installer works from the stick.

Updates forever

Plain pacman -Syu against the kutu repository over HTTPS. It's still Arch underneath: the wiki, the AUR and everything else keep working.

Nothing to regret

sudo kutu-reset returns the entire memory stack to stock Arch behavior. Every tweak is a package; every package is removable.

Light but complete

Curated XFCE with a matching dark theme, Firefox wrapped in its own memory ceiling, notifications, power management and wallpapers included.

Under the hood

locked by a tested spec

The same techniques Google and Meta run across millions of machines — on a desktop, with values fixed by a versioned design spec and asserted by a boot-time prober and CI smoke tests.

No reinstall needed

Just the packages, on your existing Arch

The whole memory stack ships as ordinary pacman packages from the kutu repository. Add the repo, install kutu-memory for the kernel-level stack — or kutu-desktop-xfce for the curated desktop on top — and undo it all with kutu-reset whenever you like.

Add to /etc/pacman.conf:

# the kutu repository
[kutu]
Server = https://kutuso.github.io/os/repo/$arch/

Then pacman -Sy kutu-memory — or grab the ISO for the full desktop.

Questions

Frequently asked

Is this just Arch Linux?

It is built from Arch packages with a custom repository of kutu packages on top, so the wiki, AUR and pacman all work. kutu-specific behavior is configuration and a handful of small packages — removable without breaking the system.

What about Secure Boot?

Not supported yet — disable it in your firmware to boot the ISO. Signed booting is tracked for a future release; the install guide states this plainly.

Does it need swap?

The installer creates a hibernation-capable swap partition by default; pick a smaller size on tiny SSDs. zswap compresses whatever swap you have, so even a small partition goes a long way.

Why not just buy more RAM?

If you can, do. This is for everyone who can't — or shouldn't have to — during the worst DRAM market in decades.
