What you get

A complete desktop that treats memory
as the scarce resource it now is

Everything ships as ordinary pacman packages with safe defaults — no config files to babysit, no daemons to babysit either.

Memory that goes further

Hot pages stay in RAM. Warm pages compress 2–3× into the zstd zswap pool. Only genuinely cold data ever touches disk — the kernel does the triage, continuously.

35%

Bounded by design

The compressed pool can never eat your RAM — the cap is locked by the design spec and asserted at boot.

Click-to-install, offline

Boot the live USB, poke around, then let the Calamares installer put it on disk. No accounts, no network, no “call home” — the installer works from the stick.

Updates forever

Plain pacman -Syu against the kutu repository over HTTPS. It's still Arch underneath: the wiki, the AUR and everything else keep working.

Nothing to regret

sudo kutu-reset returns the entire memory stack to stock Arch behavior. Every tweak is a package; every package is removable.

Light but complete

Curated XFCE with a matching dark theme, Firefox wrapped in its own memory ceiling, notifications, power management and a set of wallpapers that ship as tiny SVGs — a distro for the DRAM-shortage era shouldn't waste storage either.

Under the hood

Fleet-proven kernel machinery,
locked by a tested spec

The same techniques Google and Meta run across millions of machines — on a desktop, with values fixed by a versioned design spec and asserted by a boot-time prober and CI smoke tests.

zswap · zstdCompressed swap in RAM. Cold pages shrink to a third instead of hitting your disk.
MGLRUThe multi-generational LRU ages pages the way modern workloads actually behave.
DAMONSampling finds cold memory and reclaims it before pressure becomes stutter.
PSI + oomdPressure-driven kills target the actual hog instead of freezing your screen.
kutu-runPer-app MemoryHigh ceilings for Firefox & friends, enforced by systemd scopes.
Spec-lockedEvery tuned value is pinned by the design spec and checked by kutu-check-kernel.
Getting it

Three steps to a lighter machine

No partitioning homework, no installer account — the full walkthrough lives in the install guide.

Write the USB stick

Download the ISO, verify the SHA-256, dd it to a stick. That's the whole preparation.

Boot and explore

The live session logs in by itself. Poke around — your disk stays untouched until you say otherwise.

Click install, reboot

“Install kutu OS” copies the running system to disk offline, rebuilds the boot chain, and calibrates the memory stack on first boot.

No reinstall needed

Just the packages, on your existing Arch

The whole memory stack ships as ordinary pacman packages from the kutu repository. Add the repo, install kutu-memory for the kernel-level stack — or kutu-desktop-xfce for the curated desktop on top — and undo it all with kutu-reset whenever you like.

Add to /etc/pacman.conf:

# the kutu repository
[kutu]
Server = https://kutuso.github.io/os/repo/$arch/

Then pacman -Sy kutu-memory — or grab the ISO for the full desktop.
